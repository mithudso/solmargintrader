    Session key
    
          
    
            Creates a dedicated signing key for full-auto mode, encrypted under your
            passphrase in chrome.storage.local. The passphrase is never stored: if you lose
            it, the key cannot be reopened. The bundled key cannot place live orders because the
            required transaction verification bridge is unavailable. Creating a key does not enable trading.
