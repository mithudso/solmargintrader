# Contributor conduct

Discuss the code and evidence respectfully. Explain a reproducible problem and its
impact. Critique a proposal without attacking its author. Do not post harassment,
private information, signing keys or other secrets in issues, pull requests or logs.

Contact the repository owner about conduct concerns. This personal repository does not
promise a staffed moderation service or a response-time SLA. Security reports follow
`.github/SECURITY.md`.
