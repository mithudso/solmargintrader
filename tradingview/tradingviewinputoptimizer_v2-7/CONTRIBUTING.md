# Contributing to these component docs

Read [CLAUDE.md](CLAUDE.md), [development](docs/DEVELOPMENT.md) and [testing](docs/TESTING.md). Base behavior claims on the manifest, HTML wiring and visible source symbols. Label inference and distinguish static checks from real browser acceptance.

Keep changes scoped. Preserve upstream licensing and vendor assets. Record prompts and continuation notes with version/delta increments. The parent ignores this source bundle, so add only exact documentation paths when delivering changes. Do not blanket-stage it or rewrite another session's checkout.
