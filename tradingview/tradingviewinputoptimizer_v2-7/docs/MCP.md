# MCP and local tools

This component defines no MCP server, tool registry or local MCP configuration. The machine's global AI hub and Stele connectors are external agent services. Their presence does not add an optimizer runtime interface.

The parent hub file search may exclude vendor/generated artifacts and the ignored bundle. Use the scoped retrieval store described in `RETRIEVAL.md` for complete-directory coverage. Stele tracks the documentation/indexing task and decisions; it does not replace source files or actual query verification.
