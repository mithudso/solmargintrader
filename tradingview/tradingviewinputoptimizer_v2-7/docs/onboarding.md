# Onboarding

Read the README, component/parent agent rules, architecture and known issues. Confirm the original ignored bundle is present before following source links. Read the manifest and popup/report HTML first, then follow the background → content-script/scanner → offscreen → database message paths.

Use `docs/codebase-overview.md` for high-signal files. Use the external dossier's small digest for orientation and its file cards/sitemap for the full inventory. Use `docs/RETRIEVAL.md` to search the complete local directory; distinguish raw keyword hits, semantic paraphrase hits and static summaries.

Before implementation, isolate concurrent work and record the prompt and continuation context. After changes, run checks appropriate to the actual change. Do not report runtime acceptance from documentation/index validation alone.
